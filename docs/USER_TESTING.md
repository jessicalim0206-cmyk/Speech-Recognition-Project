# User testing protocol (minimum 5 real target users)

Target users: university students preparing for internships / first jobs.

1. Brief the participant in one sentence. Do not coach during the task.
2. Task: choose a language and category, answer two questions aloud, open the review page.
3. Record per participant (no names needed): language, device/browser, did partial text appear while speaking (Y/N),
   perceived delay (1-5), transcript accuracy (1-5), usefulness of feedback (1-5), clarity of interface (1-5), problems seen.
4. Ask: What was confusing? What would you change? Would you use it again before a real interview? Why?
5. Save results in `docs/user_testing_results.csv` with columns:
   `participant,language,device,partials_visible,delay_1to5,accuracy_1to5,feedback_1to5,ui_1to5,problems,quotes`
6. In the report: summarize with counts/means, quote real comments, state the sample size honestly, discuss limitations.

Obtain consent before recording audio or notes, and delete raw audio if participants ask.
